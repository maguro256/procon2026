# 音声タスク登録の評価データ

| ファイル | 中身 |
|---|---|
| `make_prompts.py` | 文と正解の定義。編集したら実行し直すと下の2つが作り直される |
| `prompts.csv` | 50文（core 30 = 人と合成音声、synth 20 = 合成音声のみ）と正解 |
| `reading_script.txt` | 人に読んでもらう30文の台本 |

## prompts.csv の列
- `title_keywords`: タスク名に全部含まれていれば正解とする語。`|` は「かつ」、`/` は「どれか」（表記ゆれ）
- `priority`: urgent / high / normal / low（voice/intent.py の基準どおり）
- `quantity`: 言っていなければ 1
- `deadline`: 録音日を基準に解決する。`today` `+1` `+2` `fri`（次の金曜）`next_mon`（来週の月曜）`day:28`（その月の28日）。空 = 期限なし
- `permissions`: 必要な資格コード。空 = なし
- `terms`: 文に含まれる専門語と、その語がどこにあるか。P = 今の固定語彙（DEFAULT_PROMPT）、D = 登録データ（機材名・タスク名）、N = どちらにも無い

## 録音のお願い（4人 × 30文 ≒ 1人15分）
- 実機のモジュールで、決定ボタンを押している間に1文ずつ読む
- ファイル名は `話者ID_文ID.wav`（例 `spk1_C01.wav`）。録音日もメモする（期限の正解に使う）
- 読み間違えたら読み直してよい。言いよどみはそのまま残してよい
